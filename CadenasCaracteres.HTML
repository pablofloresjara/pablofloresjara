1. Definición y Fundamentos

Según Luis Joyanes Aguilar, una cadena (string) es una secuencia de caracteres (letras, dígitos y símbolos especiales) que se trata como una unidad de datos única. Dependiendo del lenguaje de programación, puede ser un tipo primitivo o una estructura compuesta (objeto).

Codificación de Caracteres

Para que el ordenador entienda los caracteres, estos se mapean a números enteros.

  • ASCII: Estándar de 7 bits (128 caracteres). Limitado al inglés.
  • Unicode: Estándar moderno (como UTF-16 usado en C# y Java) que permite representar caracteres de casi todos los idiomas del mundo.

2. Tipos de Longitud

Basado en Sebesta (Concepts of Programming Languages), las cadenas se clasifican según cómo manejan su longitud:

Longitud Estática

La longitud se fija cuando se crea la variable (tiempo de compilación). Ejemplos: CHAR(10) en SQL o cadenas antiguas en FORTRAN.

Dinámica Limitada

Pueden variar en longitud hasta un máximo declarado. Ejemplo: Cadenas en C (arrays de char con terminador nulo \0).

Dinámica

Longitud variable sin máximo teórico (limitado solo por memoria). Requiere gestión de memoria en el Heap. Ejemplos: C#, Java, JavaScript.

3. Representación: C-Style vs Descriptores

Estilo C (Terminación Nula)

Se utiliza un carácter especial (\0) para marcar el final. No se almacena la longitud explícitamente, lo que hace que operaciones como strlen sean O(n) (deben recorrer toda la cadena).

char str[] = {'H', 'o', 'l', 'a', '\0'};

Descriptores (C# / Java)

La variable no apunta directamente a los caracteres, sino a un Descriptor u Objeto en el Heap que contiene:

  • Puntero a los datos.
  • Longitud actual (permite obtener el tamaño en O(1)).
  • Capacidad (a veces).

4. Cadenas en C# (.NET)

Según la Biblia de C# y Javier Ceballos, en .NET string es un alias de la clase System.String. Es un tipo de referencia, pero se comporta sintácticamente parecido a un tipo valor en asignaciones.

Inmutabilidad

Las cadenas en C# son inmutables. Una vez creado un objeto string, no puede modificarse.

Si haces s = s + "!";, no estás cambiando la cadena original. Estás creando un nuevo objeto en memoria y cambiando la referencia. La cadena vieja queda para el Recolector de Basura (GC).

string s1 = "Hola"; // s1 apunta a dirección 0x100 ("Hola") s1 += " Mundo"; // 1. Se crea nueva cadena "Hola Mundo" en 0x200 // 2. s1 ahora apunta a 0x200 // 3. "Hola" en 0x100 queda huérfana

Literales y Caracteres de Escape

Secuencias de escape:

  • \n : Nueva línea
  • \t : Tabulador
  • \" : Comillas dobles
  • \\ : Barra invertida

Literales "Verbatim" (@):

Permiten escribir rutas o texto multilínea sin escapar caracteres.

string ruta = @"C:\Docs\Libro.pdf";

5. Eficiencia: StringBuilder

Como las concatenaciones repetidas de string son costosas (generan mucha basura en memoria), .NET ofrece la clase System.Text.StringBuilder. Esta clase representa una cadena mutable. Utiliza un buffer interno que se expande dinámicamente.

❌ Incorrecto (Bucle Infinito)

string s = ""; for(int i=0; i<10000; i++) { s += i.ToString(); // ¡Crea 10,000 objetos! }

✅ Correcto (StringBuilder)

var sb = new StringBuilder(); for(int i=0; i<10000; i++) { sb.Append(i); // Modifica el mismo buffer } string result = sb.ToString();
