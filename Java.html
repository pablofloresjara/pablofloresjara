Programación en Java

Bienvenido al módulo de desarrollo de software. Como docentes e ingenieros, exploraremos desde la arquitectura subyacente de la Máquina Virtual de Java hasta la construcción de algoritmos estructurados usando métodos y funciones.

1. Fundamentos de Java

Creado por Sun Microsystems (ahora propiedad de Oracle) en 1995, Java es un lenguaje de programación de propósito general, tipado estáticamente y diseñado para tener la menor cantidad de dependencias de implementación posible.

Características Principales

  • Orientado a Objetos (POO): En Java, "todo es un objeto". Los programas se construyen modelando entidades del mundo real mediante clases y objetos, lo que facilita la reutilización y el mantenimiento del código (Encapsulamiento, Herencia, Polimorfismo).
  • Independencia de la Plataforma (WORA): "Write Once, Run Anywhere" (Escribe una vez, ejecuta donde sea). El código fuente de Java se compila a un código intermedio llamado Bytecode, el cual es interpretado por la Máquina Virtual de Java (JVM) de cualquier sistema operativo.
  • Robusto y Seguro: Gestión automática de memoria (Garbage Collector), manejo fuerte de tipos, y control estricto de excepciones. Java elimina los punteros explícitos (comunes en C/C++) reduciendo errores de acceso a memoria.
  • Multihilo (Multithreading): Capacidad nativa para ejecutar múltiples tareas simultáneamente, esencial en el desarrollo moderno y aplicaciones en red (Telemática).

Nota del Docente: La filosofía central de Java radica en su Máquina Virtual (JVM). Mientras que C o C++ compilan directamente a código máquina dependiente del hardware, Java introduce una capa de abstracción. Esto es vital para sistemas telemáticos donde el software debe correr en múltiples arquitecturas heterogéneas.

2. Entorno de Programación Java

Para desarrollar aplicaciones, necesitamos configurar nuestro entorno. El ecosistema se divide en tres componentes arquitectónicos fundamentales:

1. JDK (Java Development Kit)

Es el kit completo para el programador. Contiene el compilador (javac), depuradores, herramientas de empaquetado y documentación. Es lo que debes instalar para programar.

2. JRE (Java Runtime Environment)

El entorno de ejecución. Contiene las bibliotecas estándar de Java (APIs) y la JVM. Permite ejecutar programas Java, pero no compilarlos.

3. JVM (Java Virtual Machine)

El "corazón" de Java. Es el motor virtual que toma el código compilado (Bytecode) y lo traduce a instrucciones binarias entendibles por el procesador local (Windows, Mac, Linux).

El Ciclo de Vida de un Programa

1. Edición: Escribimos el código fuente en un archivo de texto. Archivo: HolaMundo.java

2. Compilación: Usamos el compilador del JDK. $ javac HolaMundo.java > (Esto genera un archivo HolaMundo.class que contiene el Bytecode)

3. Ejecución: Invocamos a la JVM para correr el programa. $ java HolaMundo > (Salida en pantalla)

Estructura Mínima de un Programa (Hola Mundo)

Todo programa en Java debe existir dentro de una class, y el punto de entrada principal es siempre el método main.

/**
 * Todo programa en Java es una clase.
 * El nombre del archivo debe coincidir EXACTAMENTE con el de la clase pública.
 */
public class HolaMundo {
    
    // Método principal: punto de entrada de la ejecución
    public static void main(String[] args) {
        // Instrucción para imprimir por consola
        System.out.println("¡Hola, mundo telemático!");
    }
}

3. Instrucciones y Tipos de Datos

Java es un lenguaje fuertemente tipado; cada variable debe ser declarada con un tipo de dato antes de ser utilizada.

Tipos de Datos Primitivos

int Enteros (32 bits)
double Decimales (64 bits)
boolean true / false
char Carácter (16 bits)

Declaración y Operadores

// Declaración y asignación
int edad = 25;
double temperatura = 36.5;
boolean estaEncendido = true;
char calificacion = 'A'; // Comillas simples para char

// Operadores Aritméticos: +, -, *, /, % (módulo)
int suma = 10 + 5; 

// Operadores Lógicos: && (AND), || (OR), ! (NOT)
boolean esValido = (edad > 18) && estaEncendido;

Estructuras de Control de Flujo

Las estructuras de control determinan la ruta de ejecución del programa basándose en condiciones y lógicas repetitivas.

1. Condicionales (if / else / switch)

int velocidad = 85;

// Condicional IF-ELSE
if (velocidad > 100) {
    System.out.println("Multa por exceso de velocidad.");
} else if (velocidad < 40) {
    System.out.println("Velocidad peligrosamente baja.");
} else {
    System.out.println("Velocidad normal.");
}

// Estructura SWITCH (Ideal para menús o estados)
int diaSemana = 3;
switch (diaSemana) {
    case 1:
        System.out.println("Lunes");
        break;
    case 2:
        System.out.println("Martes");
        break;
    case 3:
        System.out.println("Miércoles");
        break;
    default:
        System.out.println("Otro día");
}

2. Bucles / Ciclos (for / while / do-while)

// Bucle FOR: Se usa cuando se conoce la cantidad de iteraciones.
// (Inicialización ; Condición ; Incremento)
for (int i = 0; i < 5; i++) {
    System.out.println("Iteración número: " + i);
}

// Bucle WHILE: Se usa cuando NO se conoce el número exacto, depende de una condición.
int contador = 10;
while (contador > 0) {
    System.out.println("Cuenta regresiva: " + contador);
    contador--; // Decremento
}

// Bucle DO-WHILE: Garantiza que el código se ejecute AL MENOS UNA VEZ.
int clave;
do {
    // Supongamos un método que lee del teclado
    clave = leerTeclado(); 
} while (clave != 1234);

4. Funciones (Métodos en Java)

En la Programación Orientada a Objetos, a las "funciones" se les conoce como Métodos, ya que pertenecen a una Clase. Son bloques de código reutilizables que realizan una tarea específica.

Anatomía de un Método en Java:

[Modificador] [Tipo de Retorno] [Nombre]([Parámetros]) { ... }
  • Modificador: public, private, static (determina quién puede invocarlo y cómo).
  • Tipo de Retorno: Qué devuelve la función. Puede ser int, String, etc., o void si no devuelve nada.
  • Nombre: Identificador (usar notación camelCase, ej: calcularSuma).
  • Parámetros: Variables que recibe para procesar (pueden ser vacíos).
public class Calculadora {

    // 1. Método que no recibe parámetros y no retorna valor (void)
    public void saludar() {
        System.out.println("Bienvenido a la Calculadora");
    }

    // 2. Método que recibe parámetros y retorna un entero
    public int sumar(int a, int b) {
        int resultado = a + b;
        return resultado; // La palabra reservada 'return' devuelve el valor
    }

    // 3. Método estático (static)
    // Puede ser llamado sin instanciar un objeto de la clase Calculadora
    public static double calcularAreaCirculo(double radio) {
        return Math.PI * (radio * radio);
    }

    public static void main(String[] args) {
        // Uso de métodos estáticos (Directo desde la clase)
        double area = Calculadora.calcularAreaCirculo(5.0);
        
        // Uso de métodos de instancia (Requiere crear un objeto primero)
        Calculadora miCalc = new Calculadora();
        miCalc.saludar();
        
        int total = miCalc.sumar(10, 25);
        System.out.println("La suma es: " + total);
    }
}

Sobrecarga de Métodos (Overloading)

Java permite tener múltiples métodos con el mismo nombre dentro de la misma clase, siempre y cuando sus parámetros (cantidad o tipo) sean diferentes. Esto aporta gran flexibilidad.

public class Impresora {
    // Método original
    public void imprimir(int numero) {
        System.out.println("Imprimiendo número: " + numero);
    }

    // Método sobrecargado (diferente tipo de dato)
    public void imprimir(String texto) {
        System.out.println("Imprimiendo texto: " + texto);
    }

    // Método sobrecargado (diferente cantidad de parámetros)
    public void imprimir(String texto, int copias) {
        for(int i=0; i < copias; i++) {
            System.out.println("Copia " + (i+1) + ": " + texto);
        }
    }
}

Nota del Docente: Cuando pases datos a un método en Java (Paso de Parámetros), recuerda que en Java los tipos primitivos (int, double, char) se pasan por valor (se envía una copia). Los objetos y arreglos también se pasan por valor, pero ese valor es la referencia en memoria, por lo que modificar un arreglo dentro de un método alterará el arreglo original.
