Fundamentos

¿Qué es la Programación Modular?

Según Luis Joyanes Aguilar, la programación modular es uno de los métodos de diseño más flexibles y potentes para mejorar la productividad. Se basa en la estrategia de "Divide y Vencerás": descomponer un problema complejo en subproblemas más pequeños y manejables llamados módulos.

Ventajas

  • Facilita la comprensión del problema.
  • Permite la reutilización de código.
  • Simplifica el mantenimiento y la depuración.
  • Permite el trabajo en equipo simultáneo.

Abstracción

Según Sebesta y Mitchell, la modularidad es la realización física de la abstracción. Nos permite ignorar los detalles de cómo se hace algo y centrarnos en qué hace.

Estructura de un Módulo

Un módulo (subprograma, función, procedimiento o clase) consta generalmente de dos partes:

1. Interfaz (Cabecera)

Es la parte visible. Define qué hace el módulo y cómo comunicarse con él (nombre, parámetros, tipo de retorno).

2. Implementación (Cuerpo)

Es la parte oculta (Caja Negra). Contiene el código, las variables locales y la lógica de cómo realiza la tarea.

Programa Principal
Módulo A Lectura Datos
Módulo B Cálculos
Módulo C Resultados

Acoplamiento y Cohesión

Joyanes y Louden enfatizan que la calidad de un diseño modular se mide por dos criterios fundamentales. El objetivo es siempre: Alta Cohesión y Bajo Acoplamiento.

Acoplamiento (Coupling)

Objetivo: MINIMIZAR

Es el grado de interdependencia entre módulos. Si dos módulos están muy "pegados", cambiar uno rompe el otro.

Acoplamiento de Contenido (Malo): Un módulo modifica datos internos de otro.
Acoplamiento de Control: Un módulo pasa "flags" que controlan la lógica de otro.
Acoplamiento de Datos (Bueno): Se comunican solo pasando los datos necesarios por parámetros.

Cohesión (Cohesion)

Objetivo: MAXIMIZAR

Es la medida de cuán relacionadas están las tareas dentro de un solo módulo. Un módulo debe hacer una sola cosa y hacerla bien.

Cohesión Coincidental (Mala): Agrupar funciones al azar (ej. "Utilidades.cs" sin criterio).
Cohesión Temporal: Agrupar tareas porque ocurren al mismo tiempo (ej. "InicializarTodo").
Cohesión Funcional (Ideal): Todos los elementos contribuyen a una única tarea específica (ej. "CalcularImpuesto").

Alcance y Paso de Parámetros

Visibilidad de las Variables

El "Libro de Problemas" de Joyanes distingue claramente entre:

  • Variables Globales Declaradas fuera de todos los módulos. Accesibles por todos. ¡Peligro! Aumentan el acoplamiento y hacen difícil la depuración (Efectos colaterales).
  • Variables Locales Declaradas dentro de un módulo. Solo existen mientras el módulo se ejecuta. Son la base de la programación modular segura.

Paso de Parámetros

Por Valor (In)

El módulo recibe una copia del dato.

void Duplicar(int x) {
    x = x * 2; 
    // El original NO cambia
}

Por Referencia (In/Out)

El módulo recibe la dirección de memoria.

void Duplicar(ref int x) {
    x = x * 2; 
    // El original SÍ cambia
}

Implementación en C#

Basado en "La Biblia de C#" y "Microsoft C# (Ceballos)". En C#, la modularidad se implementa a través de varios niveles de abstracción:

// Un método encapsula una tarea específica.

public class Matematicas 
{
    // Módulo funcional (Función)
    public int Sumar(int a, int b) 
    {
        return a + b;
    }

    // Módulo de acción (Procedimiento/void)
    public void ImprimirResultado(int resultado) 
    {
        Console.WriteLine($"El resultado es: {resultado}");
    }
}

// La clase agrupa datos (estado) y métodos (comportamiento).

public class CuentaBancaria 
{
    // Datos privados (Ocultamiento de información)
    private decimal saldo;

    // Interfaz pública
    public void Depositar(decimal cantidad) 
    {
        if (cantidad > 0) saldo += cantidad;
    }

    public decimal ObtenerSaldo() 
    {
        return saldo;
    }
}

// Organización lógica y física de módulos grandes.

// Archivo: Geometria.cs
namespace MiProyecto.Geometria 
{
    public class Circulo { /* ... */ }
    public class Rectangulo { /* ... */ }
}

// Archivo: Programa.cs
using MiProyecto.Geometria; // Importando el módulo

class Program {
    static void Main() {
        Circulo c = new Circulo();
    }
}
