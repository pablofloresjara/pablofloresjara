1. Control en Proyectos de Software

Métricas de Proceso y Proyecto

Según Pressman, "no se puede gestionar lo que no se puede medir". El control se basa en la recolección de métricas para evaluar el estado del proyecto.

  • Métricas Orientadas al Tamaño: Líneas de Código (LOC).
  • Métricas Orientadas a la Función: Puntos de Función (PF).
  • Métricas de Calidad: Corrección, facilidad de mantenimiento, integridad y facilidad de uso.

Seguimiento y Control

Consiste en asegurar que el proyecto se mantiene dentro de los límites de tiempo y presupuesto definidos.

"El gestor de proyectos debe supervisar el progreso, detectar desviaciones y aplicar acciones correctivas de inmediato."

2. Control de la Calidad del Software

Garantía de Calidad (SQA)

La SQA es una "actividad de protección" que se aplica a lo largo de todo el proceso de ingeniería. No es solo probar el código al final.

Revisiones Técnicas Formales (RTF): El filtro principal para encontrar errores antes de que se conviertan en defectos costosos.
Estándares: Cumplimiento de normas como ISO 9000 o modelos CMMI para asegurar procesos predecibles.

Factores de Calidad de McCall:

Corrección Fiabilidad Eficiencia Integridad Facilidad de Uso Flexibilidad

3. Gestión de Configuración del Software (GCS)

La GCS es un conjunto de actividades diseñadas para identificar, controlar y auditar los cambios en los elementos de configuración del software (ECS) a lo largo del ciclo de vida.

01

Identificación

Definir qué objetos (código, documentos, diagramas) son críticos y deben ser controlados. Creación de la Línea Base (Baseline).

02

Control de Cambios

Evaluar el impacto de un cambio propuesto, aprobarlo o rechazarlo mediante un comité (CCB). Previene la corrupción del sistema.

03

Auditoría y Reporte

Verificar que los cambios se realizaron conforme a lo aprobado. Mantener el historial de "quién, qué y cuándo".

Análisis del Software en GCS

El análisis consiste en entender la trazabilidad. Si cambio un requisito, ¿qué módulos de código se ven afectados? La GCS proporciona las herramientas para este análisis de impacto, reduciendo el riesgo de efectos colaterales.
