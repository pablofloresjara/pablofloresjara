Arreglos (Arrays/Vectores)

Un arreglo es una colección finita, homogénea y ordenada de elementos. Se almacenan en posiciones contiguas de memoria, lo que permite un acceso extremadamente rápido mediante índices.

  • Acceso Directo: Complejidad O(1) para leer cualquier elemento.
  • Homogeneidad: Todos los datos deben ser del mismo tipo (ej. todos int).
  • Tamaño Fijo: Se debe definir su capacidad al crearlo (en C# estándar).
C# Syntax 
int[] numeros = new int[5];

// Asignación directa
numeros[0] = 10;
numeros[1] = 20;

// Declaración e inicialización
string[] nombres = { "Ana", "Luis", "Pepe" };

Dinámico

Listas Enlazadas

Estructura dinámica donde los elementos (nodos) están dispersos en memoria. Cada elemento apunta al siguiente. Es ideal cuando no sabemos cuántos elementos vamos a almacenar.

Nota Importante: En C#, la clase List<T> en realidad implementa un arreglo dinámico redimensionable, pero conceptualmente actúa como una lista. Para una lista enlazada real se usa LinkedList<T>.

C# LinkedList 
LinkedList<string> lista = new LinkedList<string>();

// Añadir nodos
lista.AddLast("Origen");
lista.AddLast("Destino");
lista.AddFirst("Inicio Real");

// Recorrido O(n)
foreach (var nodo in lista) {
    Console.WriteLine(nodo);
}

Pilas (Stacks)

Last In, First Out

Una estructura restringida donde las inserciones y eliminaciones se realizan solo por un extremo llamado "tope" (top). Es como una pila de platos: el último que pones es el primero que sacas.

Operaciones Clave:

  • Push(x) Inserta un elemento en el tope.
  • Pop() Elimina y devuelve el elemento del tope.
  • Peek() Mira el tope sin eliminarlo. 
Stack<int> pila = new Stack<int>();

pila.Push(1);
pila.Push(2);
pila.Push(3);

int tope = pila.Pop(); // Retorna 3
// Ahora el tope es 2

Colas (Queues)

First In, First Out

Estructura donde el primer elemento en entrar es el primero en salir. Simula una fila en el supermercado o la cola de impresión de documentos.

Operaciones Clave:

  • Enqueue(x) Añade al final.
  • Dequeue() Saca del frente. 
Queue<string> cola = new Queue<string>();

cola.Enqueue("Cliente A");
cola.Enqueue("Cliente B");

string atendido = cola.Dequeue(); 
// Retorna "Cliente A"
