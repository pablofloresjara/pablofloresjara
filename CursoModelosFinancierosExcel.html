Módulo 2: Herramientas Fundamentales de Modelado

1. Definiciones Clave

  • Modelo Financiero: Representación matemática (en Excel) de la realidad financiera de una empresa o proyecto.
  • Análisis de Sensibilidad (What-If): Proceso de cambiar *Inputs* para ver cómo cambia el *Output*.
  • Tabla de Datos: Herramienta de Excel para realizar Análisis de Sensibilidad de 1 o 2 variables automáticamente.
  • Administrador de Escenarios: Permite guardar y comparar grupos de inputs (Ej. Pesimista, Base, Optimista).

2. Ejemplo Detallado: Tabla de Datos de 2 Variables

Imagina un modelo simple de Utilidad = (Precio - Costo) * Unidades. Queremos ver cómo cambia la Utilidad si movemos el Precio y las Unidades.

  1. Construir el Modelo Base:
    • C1 (Precio): 10
    • C2 (Costo): 6
    • C3 (Unidades): 1000
    • C5 (Utilidad): =(C1-C2)*C3 (Resultado: 4000)
  2. Preparar la Matriz:
    • En B9, vincular la fórmula de resultado: =C5.
    • En la fila 9 (C9, D9, ...), poner los precios (ej. 8, 9, 10, 11).
    • En la columna B (B10, B11, ...), poner las unidades (ej. 800, 900, 1000).
  3. Ejecutar la Tabla:
    • Seleccionar todo el rango B9:G14 (ejemplo).
    • Ir a Datos > Análisis Y si > Tabla de Datos...
    • Celda de entrada (Fila): C3 (la variable de las filas: Unidades).
    • Celda de entrada (Columna): C1 (la variable de las columnas: Precio).
    • Aceptar. Excel llena la tabla.

3. Ejercicios (1-3)

Ejercicio 1: Cálculo del VNA (Valor Neto Actual)

Objetivo: Determinar si un proyecto es rentable usando la función VNA (o NPV).

Datos Valor Celda (Ejemplo)
Tasa Descuento 10% B1
Inversión (Año 0) -100,000 B4
Flujo Año 1 25,000 B5
Flujo Año 2 30,000 B6
Flujo Año 3 40,000 B7
Flujo Año 4 45,000 B8

Resolución:

En una celda, escribe: =VNA(B1, B5:B8) + B4

Resultado: $11,882.83. (Conclusión: VNA > 0, el proyecto es rentable).

Ejercicio 2: Cálculo de la TIR (Tasa Interna de Retorno)

Objetivo: Encontrar la rentabilidad intrínseca del proyecto del Ejercicio 1 usando TIR (o IRR).

Resolución:

Se usa el rango completo, incluyendo la inversión inicial.

En una celda, escribe: =TIR(B4:B8)

Resultado: 15.09%. (Conclusión: 15.09% (TIR) > 10% (Tasa Descuento), el proyecto es rentable).

Ejercicio 3: Tabla de Datos (1 Variable)

Objetivo: Ver cómo cambia el VNA (celda B10 del Ej. 1) si cambia la Tasa de Descuento (celda B1).

Resolución:

  1. En C4 a C8, poner tasas (ej. 8%, 9%, 10%, 11%, 12%).
  2. En D3, vincular el resultado: =B10 (la fórmula del VNA).
  3. Seleccionar C3:D8.
  4. Datos > Tabla de Datos...
  5. Celda de entrada (Fila): (dejar en blanco).
  6. Celda de entrada (Columna): B1 (la Tasa de Descuento original).

Resultado: La columna D se llenará con los VNA para cada tasa, mostrando cómo el VNA disminuye si la tasa sube.

Módulo 3: Construcción de un Modelo Financiero Base (Proyecciones)

1. Principios Clave

  • Pro-Forma: Un estado financiero que mira hacia el futuro (proyección).
  • Inputs, Procesos, Outputs: La regla de oro.
    • Inputs: Suposiciones (ej. Crecimiento 8%). Ponerlos arriba y en azul.
    • Procesos: Fórmulas y cálculos.
    • Outputs: Resultados clave (ej. Utilidad Neta).

2. Ejemplo Detallado: P&G Pro-Forma a 3 Años

Construiremos un modelo que proyecte la Utilidad Neta.

  1. Paso 1: Configurar Inputs (Suposiciones)
    • C3 (Unidades Año 1): 1000
    • C4 (Crecimiento Ventas): 8%
    • C5 (Precio Venta): $50
    • C6 (Costo Variable %): 40%
    • C7 (Costos Fijos): $15,000
    • C8 (Tasa Impuestos): 25%
  2. Paso 2: Estructurar P&G (Procesos)
    • Columnas: Año 1, Año 2, Año 3.
    • Filas: Ventas, Costo de Ventas, Utilidad Bruta, Costos Fijos, EBIT, Impuestos, Utilidad Neta.
  3. Paso 3: Rellenar Fórmulas (Conectando Inputs)
    • Unidades Año 1: =C3
    • Unidades Año 2: =C14*(1+$C$4) (Asumiendo que C14 es Unidades Año 1. Usar $ para fijar la celda de crecimiento).
    • Ventas (Año 1): =Unidades_Año_1 * $C$5
    • Costo Ventas (Año 1): =Ventas_Año_1 * $C$6
    • Utilidad Bruta (Año 1): =Ventas_Año_1 - Costo_Ventas_Año_1
    • Costos Fijos (Año 1): =$C$7
    • EBIT (Año 1): =Utilidad_Bruta_Año_1 - Costos_Fijos_Año_1
    • Impuestos (Año 1): =EBIT_Año_1 * $C$8
    • Utilidad Neta (Año 1): =EBIT_Año_1 - Impuestos_Año_1
    • Copiar todas las fórmulas hacia la derecha para Año 2 y Año 3.

3. Ejercicios (4-6)

Ejercicio 4: Administrador de Escenarios

Objetivo: Comparar 3 escenarios (Base, Pesimista, Optimista) para nuestro P&G.

Resolución:

  1. Ir a Datos > Análisis Y si > Administrador de Escenarios...
  2. Agregar... "Base". Celdas cambiantes: C3,C4,C5. Valores: 1000, 8%, 50.
  3. Agregar... "Pesimista". Celdas cambiantes: C3,C4,C5. Valores: 800, 5%, 45.
  4. Agregar... "Optimista". Celdas cambiantes: C3,C4,C5. Valores: 1200, 10%, 55.
  5. Hacer clic en Resumen...
  6. Celda de resultado: E24 (Utilidad Neta Año 3 del P&G).

Resultado: Excel crea una nueva hoja con un resumen comparativo de la Utilidad Neta del Año 3 para los tres escenarios.

Ejercicio 5: Evaluación de un Préstamo (Función PAGO)

Objetivo: Calcular la cuota mensual para un préstamo de $50,000 a 5 años con una tasa anual del 12%.

Datos:

  • Monto (va): 50000
  • Tasa Anual: 12%
  • Años: 5

Resolución:

La función PAGO (o PMT) requiere que la tasa y el plazo estén en la misma unidad.

  • Tasa mensual (tasa): 12% / 12 = 1%
  • N° de Meses (nper): 5 * 12 = 60

Fórmula: =PAGO(1%, 60, 50000)

Resultado: -$1,112.22 (negativo porque es una salida de dinero).

Ejercicio 6: Modificación del P&G (Inputs Variables)

Objetivo: Modificar el P&G del Módulo 3 para que el Precio también crezca un 3% anual.

Resolución:

  1. Añadir Input: C9 (Crec. Precio): 3%
  2. Insertar fila en el P&G: "Precio de Venta".
  3. Precio Año 1: =$C$5
  4. Precio Año 2: =Precio_Año_1 * (1 + $C$9) (fijar C9).
  5. Copiar fórmula de Precio Año 2 a Año 3.
  6. Modificar fórmula de Ventas (Año 1): =Unidades_Año_1 * Precio_Año_1 (ya no se fija el precio C5).
  7. Copiar fórmula de Ventas a Año 2 y 3.

Resultado: La Utilidad Neta ahora será mayor en los años 2 y 3, ya que el precio aumenta.

Módulo 4: Evaluación de Proyectos de Inversión (DCF)

1. Definiciones Clave

  • Flujo de Caja Libre (Free Cash Flow - FCF): Es el dinero real que genera el negocio, disponible para pagar a inversores (deuda y capital). Es diferente de la Utilidad Neta.
  • Fórmula FCF (simplificada): FCF = EBIT * (1 - Tasa Impuestos) + Depreciación - CAPEX - ΔCapital de Trabajo
  • Payback (Período de Recuperación): El tiempo (en años) que tarda un proyecto en recuperar su inversión inicial.
  • Payback Descontado: Igual que el Payback, pero usa flujos de caja descontados (traídos a valor presente). Es más preciso.

2. Ejercicios (7-9)

Ejercicio 7: Payback Simple

Objetivo: Calcular el período de recuperación simple.

Año Flujo Flujo Acumulado
0 -100,000 -100,000
1 30,000 -70,000
2 40,000 -30,000
3 50,000 20,000
4 50,000 70,000

Resolución:

El último año negativo es el Año 2 (aún faltan $30,000 por recuperar). El Año 3 genera $50,000.

Fórmula: Año del último negativo + (Monto faltante / Flujo del siguiente año)

2 + (30,000 / 50,000)

Resultado: 2.6 años.

Ejercicio 8: Payback Descontado

Objetivo: Calcular el payback usando flujos descontados (Tasa: 10%).

Año Flujo Flujo Descontado (=Flujo / (1+10%)^Año) Acumulado Descontado
0 -100,000 -100,000 -100,000
1 30,000 27,273 -72,727
2 40,000 33,058 -39,669
3 50,000 37,566 -2,103
4 50,000 34,151 32,048

Resolución:

El último año negativo es el 3 (faltan $2,103). El Año 4 genera $34,151 descontados.

3 + (2,103 / 34,151)

Resultado: 3.06 años. (Nota: Es más largo que el payback simple, como debe ser).

Ejercicio 9: Cálculo de Flujo de Caja Libre (FCF)

Objetivo: Calcular el FCF del Año 1 con los siguientes datos.

EBIT (Utilidad Operativa) $50,000
Tasa Impuestos 25%
Depreciación (Gasto no-caja) $10,000
CAPEX (Inversión en Activos) -$15,000
ΔCapital de Trabajo (Aum. en Cuentas por Cobrar) -$5,000

Resolución (Fórmula FCF):

= (EBIT * (1 - Tasa Imp.)) + Depreciación - CAPEX - ΔCapital

= (50000 * (1 - 0.25)) + 10000 - 15000 - 5000

= 37,500 + 10,000 - 15,000 - 5,000

Resultado: $27,500. (Este es el flujo que se usa para VNA y TIR en modelos reales).

Módulo 5: Introducción a la Simulación de Monte Carlo

1. Definiciones Clave

La simulación de Monte Carlo nos permite modelar la incertidumbre. En lugar de decir "Las ventas serán 1000", decimos "Las ventas estarán *entre* 800 y 1200".

  • Incertidumbre vs. Riesgo: El riesgo es una incertidumbre que *importa* (ej. la probabilidad de perder dinero).
  • ALEATORIO(): Devuelve un número aleatorio entre 0 y 0.999... (Distribución Uniforme).
  • ALEATORIO.ENTRE(min, max): Devuelve un número entero aleatorio entre min y max.
  • Distribución Uniforme: Todos los valores en un rango son igualmente probables (ej. ALEATORIO.ENTRE).
  • Distribución Normal: Los valores cercanos a la media son más probables. Se define por su media y desviación estándar.

2. Ejercicios (10-12)

Ejercicio 10: Simular un Dado

Objetivo: Simular el lanzamiento de un dado de 6 caras.

Resolución:

=ALEATORIO.ENTRE(1, 6)

Resultado: Un número entero: 1, 2, 3, 4, 5, o 6. (Presiona F9 para recalcular).

Ejercicio 11: Simular Ventas (Uniforme)

Objetivo: Simular las Unidades Vendidas, que creemos estarán entre 500 y 1500 (cualquier valor es igual de probable).

Resolución:

=ALEATORIO.ENTRE(500, 1500)

Ejercicio 12: Simular Crecimiento (Normal)

Objetivo: Simular el Crecimiento de Ventas. Creemos que la media será 8%, con una desviación estándar del 2%. (Valores cercanos a 8% son más probables).

Resolución:

Usamos la inversa de la distribución normal.

=INV.NORM.N(ALEATORIO(), 0.08, 0.02)

Resultado: Un número aleatorio (ej. 0.075, 0.091, 0.063). La mayoría (aprox. 68%) estará entre 6% y 10%.

Aquí es donde unimos todo. Tomaremos nuestro P&G (Módulo 3), reemplazaremos los inputs fijos por inputs aleatorios (Módulo 5) y usaremos una Tabla de Datos (Módulo 2) para ejecutar miles de simulaciones.

Ejercicios (13-16)

Ejercicio 13: P&G con 1 Variable Aleatoria

Objetivo: Modificar el P&G (Módulo 3) para que el "Crecimiento Ventas" (C4) ya no sea 8% fijo.

Resolución:

Reemplaza el valor en la celda C4 (nuestro Input) con la fórmula del Ejercicio 12:

=INV.NORM.N(ALEATORIO(), 0.08, 0.02)

Resultado: Ahora, cada vez que presionas F9, el crecimiento cambia, y toda la proyección P&G (Año 2 y 3) se recalcula.

Ejercicio 14: Simulación de 1000 Ensayos (Tabla de Datos)

Objetivo: Ejecutar 1000 simulaciones de nuestro P&G aleatorio y registrar la Utilidad Neta del Año 3 (E24).

Resolución (El gran truco):

  1. En G1, escribe "Ensayo". En H1, escribe "Utilidad Año 3".
  2. En G2 a G1001, escribe los números 1 a 1000.
  3. En H2, vincula el resultado: =E24 (Utilidad Neta Año 3).
  4. Selecciona el rango G2:H1001. (Importante: NO incluir H1).
  5. Datos > Tabla de Datos...
  6. Celda de entrada (Fila): (dejar en blanco).
  7. Celda de entrada (Columna): A1 (¡Selecciona CUALQUIER celda que esté vacía y no se use en el modelo!).

Resultado: Excel llena la columna H con 1000 resultados diferentes de la Utilidad Neta Año 3. Ha forzado a ALEATORIO() a recalcularse 1000 veces.

Ejercicio 15: Análisis de Resultados (Estadísticas)

Objetivo: Analizar los 1000 resultados de la columna H2:H1001.

Resolución:

  • Promedio: =PROMEDIO(H2:H1001)
  • Desv. Estándar: =DESVEST.M(H2:H1001)
  • Mínimo: =MIN(H2:H1001)
  • Máximo: =MAX(H2:H1001)
  • Percentil 10: =PERCENTIL.INC(H2:H1001, 0.1)

Resultado: Ahora no solo tienes "un" resultado, sino el rango completo de futuros posibles.

Ejercicio 16: Probabilidad de Pérdida (CONTAR.SI)

Objetivo: Calcular la probabilidad (en %) de que perdamos dinero (Utilidad Neta < 0) en el Año 3.

Resolución:

Contamos cuántos de los 1000 ensayos fueron negativos y lo dividimos por 1000.

=CONTAR.SI(H2:H1001, "<0") / 1000

Resultado: Ej. 0.12 ó 12%. (Conclusión: "Jefe, según 1000 simulaciones, hay un 12% de probabilidad de que perdamos dinero en el Año 3").

Módulo 7: Técnicas Avanzadas y Presentación

1. Definiciones Clave

  • Buscar Objetivo (Goal Seek): Permite encontrar el *Input* necesario para lograr un *Output* deseado. (Ej. ¿Qué precio necesito para una Utilidad de 10k?).
  • Solver: Una herramienta avanzada (Add-in) de optimización. Puede encontrar el *Input* que *maximiza* o *minimiza* un *Output*, sujeto a múltiples restricciones.
  • Dashboard: Un panel de control visual para presentar los resultados del modelo. Usa Controles de Formulario (ej. barras deslizantes) para hacer el modelo interactivo.
  • SIERROR (o IFERROR): Función para "atrapar" errores (ej. #DIV/0!) y mostrar un mensaje amigable.

2. Ejercicios (17-20)

Ejercicio 17: Buscar Objetivo (Goal Seek)

Objetivo: Usando el P&G original (Módulo 3), ¿qué "Precio Venta" (C5) necesitamos para que la "Utilidad Neta Año 1" (C24) sea exactamente $5,000?

Resolución:

  1. Ir a Datos > Análisis Y si > Buscar Objetivo...
  2. Definir la celda: C24 (Utilidad Neta Año 1)
  3. Con el valor: 5000
  4. Para cambiar la celda: C5 (Precio Venta)

Resultado: Excel encontrará el precio exacto (ej. $52.78) que logra esa utilidad.

Ejercicio 18: Optimización (Solver)

Objetivo: Maximizar la "Utilidad Neta Año 3" (E24) cambiando el "Precio" (C5) y las "Unidades Año 1" (C3).

Restricciones:

  • El Precio (C5) no puede ser mayor a $55.
  • Las Unidades (C3) no pueden ser mayores a 1300.

Resolución:

  • Ir a Datos > Solver (Quizás tengas que activarlo en Opciones > Complementos).
  • Establecer Objetivo: E24
  • Para: Max
  • Cambiando las celdas: C3, C5
  • Sujeto a las restricciones:
    • C3 <= 1300 (Agregar...)
    • C5 <= 55 (Agregar...)
  • Resolver.

    • Resultado: Solver encontrará la combinación óptima (en este caso, 1300 unidades y $55) que maximiza la utilidad.

    Ejercicio 19: Dashboard (Control Deslizante)

    Objetivo: Añadir una barra deslizante que controle el "Crecimiento Ventas" (C4) de 0% a 20%.

    Resolución:

    1. Activar pestaña Programador (o Desarrollador).
    2. Ir a Insertar > Controles de Formulario > Barra de desplazamiento.
    3. Dibujar la barra en la hoja.
    4. Clic derecho en la barra > Formato de control...
    5. Vincular con la celda: J1 (una celda auxiliar).
    6. Valor actual: 8. Valor mínimo: 0. Valor máximo: 20.
    7. Ahora J1 mostrará un número entero (0-20) según muevas la barra.
    8. Modifica el Input C4. Borra el 8% y escribe: =J1/100.

    Resultado: Ahora puedes mover la barra deslizante y verás cómo toda la proyección P&G cambia en tiempo real.

    Ejercicio 20: Control de Errores (SIERROR)

    Objetivo: Evitar que una fórmula muestre #DIV/0! si un Input está vacío.

    Contexto: Tienes una fórmula =A1/A2. Si A2 está vacío o es 0, muestra error.

    Resolución:

    Envuelve la fórmula en SIERROR (o IFERROR).

    =SIERROR(A1/A2, "Revisar Inputs")

    Resultado: Si A2 es 0, la celda mostrará "Revisar Inputs" en lugar de un error feo.
