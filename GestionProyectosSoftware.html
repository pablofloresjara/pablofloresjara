Sección 2.1

Planificación de Proyectos

Determinación del Ámbito

Definición clara de funciones, rendimiento, restricciones e interfaces. Es el primer paso crítico para evitar el "scope creep".

Estimación de Recursos

Evaluación de personas (el recurso más importante), componentes de software reutilizables y el entorno de hardware/software necesario.

Análisis de Riesgos

Identificación proactiva de posibles fallos técnicos, de negocio o de gestión para crear planes de contingencia efectivos.

"Nadie planea fracasar, pero muchos fracasan por no planear."

En la planificación usamos métricas históricas (LDC o Puntos de Función) para predecir el esfuerzo y la duración del proyecto.

Sección 2.2

Estructura Orgánica

La organización de las personas determina el éxito del producto. No existe un modelo único, sino el adecuado para el problema.

Descentralizado Democrático

No existe un líder permanente. Las decisiones se toman por consenso grupal. Excelente para problemas complejos de baja modularidad que requieren alta creatividad.

Alta Satisfacción Mucha Comunicación

Controlado Centralizado

Estructura jerárquica clásica. Un jefe de proyecto coordina y decide. Ideal para tareas altamente modulares y rutinarias donde la eficiencia es prioritaria.

Eficiencia Orden Vertical

Descentralizado Controlado

Un líder definido pero con una gestión de tareas distribuida. Equilibra la autoridad con la participación activa de los sub-líderes.

Sección 2.3

Mediciones en Producto y Proceso

Métricas de Producto

  • Complejidad:

    Mide la lógica interna (ej. Complejidad Ciclomática de McCabe).

  • Tamaño:

    Volumen físico del software (LDC) o funcionalidad entregada (PF).

  • Calidad:

    Densidad de defectos, facilidad de mantenimiento y usabilidad.

Métricas de Proceso

  • Productividad:

    Relación entre el esfuerzo (hombres-mes) y el producto generado.

  • Efectividad:

    Capacidad de encontrar errores antes de entregar el software (EED).

  • Coste:

    Desviación entre el presupuesto planificado y el real.
