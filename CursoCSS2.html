Curso de CSS: De Cero a Héroe

Orientado a estudiantes de Ingeniería de Sistemas

¿Qué es CSS y por qué es fundamental?

CSS (Cascading Style Sheets) es el lenguaje que usamos para describir la presentación de un documento HTML. Es la piedra angular del diseño web moderno y, para un ingeniero de sistemas, dominarlo es crucial.

  • Separación de Intereses: Permite separar la estructura (HTML) de la presentación (CSS), haciendo el código más limpio y mantenible.
  • Flexibilidad y Escalabilidad: Facilita la creación de diseños complejos y la aplicación de un mismo estilo a múltiples páginas.
  • Dinamismo: En conjunto con JavaScript y el DOM, CSS permite crear interfaces de usuario interactivas y animadas.
  • Optimización: Un CSS bien estructurado reduce el peso de las páginas y mejora los tiempos de carga.

Módulo 1: Fundamentos y Sintaxis

1.1 Sintaxis Básica

La sintaxis de CSS se compone de un selector y un bloque de declaración.

selector {
    propiedad: valor;
    /* Ejemplo: */
    h1 {
        color: #CC9900;
        font-size: 2rem;
    }
}

1.2 Tres Formas de Aplicar CSS

1. En Línea (Atributo)

Aplica estilos directamente a un elemento. (No recomendado para mantenibilidad).

<p style="color: red;">...</p>

2. Interna (Cabecera)

Define estilos en el `` de la página. Útil para estilos de una sola página.

<style>
    p { text-align: right; }
</style>

3. Hoja Externa (Enlace)

Mejor Práctica. Vincula un archivo `.css` externo. Ideal para sitios completos.

<link rel="stylesheet" href="estilo.css">

Módulo 2: El Poder de los Selectores

Los selectores son el corazón de CSS. Nos permiten "seleccionar" los elementos HTML que queremos estilizar.

2.1 Selectores Básicos

  • h1, p, b - Por Elemento (Agrupados)
  • .enfatizada - Por Clase General
  • p.enfatizada - Por Clase en Elemento
  • #enfatizada - Por ID (Debe ser único)

2.2 Pseudo-Clases y Elementos

Permiten estilizar elementos basados en su estado o posición.

  • :hover - Estado (mouse encima)
  • :link - Enlace no visitado
  • :visited - Enlace visitado
  • :first-child - Primer hijo de un padre
  • ::first-line - Primera línea de un texto
  • ::first-letter - Primera letra de un texto

Módulo 3: El Modelo de Caja (Box Model)

Todo elemento en la web es una caja rectangular. El "Box Model" describe cómo se calcula el tamaño de esta caja.

  • Content: El contenido (texto, imagen).
  • Padding: Espacio interno, entre el contenido y el borde.
  • Border: La línea que rodea al padding y contenido.
  • Margin: Espacio externo, fuera del borde. Separa esta caja de otras.

Pro Tip: Usa siempre box-sizing: border-box;. Esto hace que el `padding` y `border` se incluyan en el `width` y `height` totales, facilitando enormemente los cálculos de layout.

Módulo 4: Layouts Modernos (Temas Avanzados)

4.1 Flexbox

Es un modelo de layout unidimensional (1D) diseñado para distribuir espacio entre ítems en un contenedor, incluso cuando sus tamaños son desconocidos o dinámicos.

  • Perfecto para alinear ítems (horizontal o verticalmente).
  • Ideal para barras de navegación, listados y centrado.
  • Controla dirección, alineación, justificación y orden.
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}

4.2 CSS Grid

Es un modelo de layout bidimensional (2D). Permite crear diseños complejos basados en filas y columnas, similar a una tabla pero mucho más potente y flexible.

  • Perfecto para el layout general de la página.
  • Permite superponer elementos fácilmente.
  • Control total sobre filas y columnas.
.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 1rem;
}

Módulo 5: Diseño Responsivo (Media Queries)

El Diseño Responsivo asegura que tu aplicación web se vea y funcione bien en todos los dispositivos (móviles, tablets, desktops). La herramienta principal para esto son las Media Queries.

Una Media Query permite aplicar un bloque de CSS solo si una condición específica (como el ancho de la pantalla) es verdadera.

/* Estilos base (móvil primero) */
.container {
    width: 100%;
}

/* Estilos para pantallas más grandes (ej. tablets y más) */
@media (min-width: 768px) {
    .container {
        width: 750px;
        background-color: #1E293B; /* bg-slate-800 */
    }
}
